# MEK Boutique

A modern boutique e-commerce website built with Next.js, React and TypeScript.

## Overview

MEK Boutique is a responsive e-commerce website concept created as a personal portfolio project.

The project focuses on a clean, modern interface and a smooth shopping experience across desktop and mobile devices.

## Features

- Responsive design
- Product browsing
- Shopping cart
- Contact page
- Brand presentation
- Mobile-friendly layout

## Tech Stack

- Next.js
- React
- TypeScript
- CSS

## Getting Started

First, run the development server:

```bash
npm run dev
